# Proyecto Aulia 

Backend oficial de AULIA, una plataforma académica orientada al acompañamiento socioemocional y la gestión educativa para equipos de orientación escolar.

El proyecto busca facilitar la detección temprana, el seguimiento y la intervención institucional mediante una experiencia digital moderna, accesible y centrada en las personas.

---

## Tecnologías utilizadas

- JavaScript (ES6+)
- Express
- PostgreSQL
- Sequelaze
- Dotenv
- JWT
- Cookies
- Joi Validator

## Convenciones del proyecto

- Arquitectura multicapas.
- Arquitectura modular y escalable.
- Separación de responsabilidades.
- Utilización de variables de entorno.
- Autenticación con JWT y autorización por roles.
